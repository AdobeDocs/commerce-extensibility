# Return extension points (V2)

The Adobe Commerce Admin UI SDK allows you to add [custom view buttons](view-button.md) to return (RMA) detail pages in the Adobe Commerce Admin.

Declare return extensions under `adminUi.rma`. Returns support `viewButtons` only, not grid columns or mass actions.
