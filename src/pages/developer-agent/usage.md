# View your usage

The **Usage** tab displays the percentage of your org's capacity that has been used. Currently, the allocated capacity is provided at no additional charge. Expanded usage details and pricing information will be available at a later date.

## Request additional capacity

If you need additional capacity, contact your Adobe Commerce representative. An administrator can also raise your organization's limit in the Adobe Admin Console.

## Organization usage this cycle

The **Organization usage this cycle** section displays your organization's total usage for the current cycle as a percentage of your org's capacity.

This capacity is shared across all members of your organization and resets at the start of each cycle.

## Usage by project

The **Usage by project** section lists the usage attributed to each project during the current cycle.

## Usage by member

The **Usage by member** section shows each member's share of the organization total, so you can see how usage is distributed across your team.
