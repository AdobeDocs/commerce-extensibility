# Credit memo extension points (V2)

The Adobe Commerce Admin UI SDK allows you to make modifications to the following elements on the **Sales** > **Credit Memos** page in the Adobe Commerce Admin:

* Add [grid columns](grid-columns.md) backed by runtime actions to the credit memo grid.
* Add [custom attribute grid columns](custom-attribute-grid-columns.md) backed by stored custom attributes, with optional filters.
* Add [custom view buttons](view-button.md) to the credit memo detail page.
